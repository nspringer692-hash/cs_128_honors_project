# RUN.md

## How to run Ferroforge

1. Run 'git clone https://github.com/nspringer692-hash/cs_128_honors_project.git'.
   - Ideally, you should run this in the Visual Studio Code terminal.
2. Run 'cargo run'.
   - This may take a while. Bevy and bevy_egui need time to be added and compiled on your machine!
3. Enjoy!
